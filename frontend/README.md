# Xenon Frontend (Web Portal)

The official web dashboard and portal for the **Xenon** tourism platform. Built for speed and scalability using **React** and **Vite**, this frontend serves multiple user roles, providing dedicated interfaces for Administrators, Vendors, and Clients.

## 🌟 Key Features
- **Multi-Role Architecture:** Dedicated routing and portal access for `Admin`, `Vendor`, and `Client`.
- **Authentication & Onboarding:** Login, Password Recovery, and specialized Registration flows for both Travelers and Vendors.
- **Dashboards & Analytics:** Comprehensive overview pages for monitoring platform metrics and activities.
- **Platform Management Tools:**
  - Staff Management
  - Payments and Transactions Tracking
  - Notifications Center
- **Modern & Responsive UI:** Fast, client-side routing and consistent iconography.

## 🛠️ Tech Stack
- **Framework:** React.js 19
- **Build Tool:** Vite
- **Routing:** React Router DOM (v7)
- **Icons:** Lucide React
- **Linting:** ESLint

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Run Tests:**
   ```bash
   npm run test
   ```
